# Sample data (SAMPLE / DEMO DATA)

Everything in this folder is **fictional** and was generated by
[`scripts/generate_sample_data.py`](../scripts/generate_sample_data.py) (fixed random seed, so it
regenerates identically).

- **Company:** "Demo Gulf Holding Co.", a made-up holding company in Jeddah.
- **Vendors:** 15 invented names, each ending in "Demo" (for example "Coastal Cleaning Demo Co."). Any resemblance to a real business is accidental.
- **People:** invented names; all addresses use the reserved `.example` domain, which cannot receive mail.
- **Amounts:** SAR, with 15% VAT added to round net amounts; annual contract values between SAR 18,000 and 480,000.
- **Dates:** set relative to the demo as-of date, **22 Nov 2026** (a Sunday), so every alert band, ageing bucket and chaser stage appears at least once.

| File | Rows | What it holds |
|---|---:|---|
| `contracts.csv` | 36 | Contract register: vendor, owner, start/end, notice period, auto-renew, value, status, renewal decision |
| `invoices.csv` | 85 | Vendor invoices: dates, amount, status, approver, paid date, last chased, chasers sent |
| `audit_requests.csv` | 30 | Items requested by the (fictional) external auditor, internal audit and a ZATCA e-invoicing readiness check |
| `vendors.csv` | 15 | Vendor contacts |
| `config.toml` | - | Every threshold the rules use |

Nothing here describes real contracts, vendors, invoices, audits or employers.
